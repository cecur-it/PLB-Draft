llm-gateway-down	LLM gateway down	Check the container, the Ollama workers and certificates; Vendetta alerts continue without AI enrichment

llm-triage-latency	LLM triage latency	Check queue depth, GPU memory, model eviction and concurrency (GATEWAY_MAX_CONCURRENCY)

llm-prompt-injection-burst	LLM prompt injection burst	Find the source host in cs3-ai-inference-* (guardrail field), isolate it, keep the blocking on

llm-audit-chain-broken	LLM audit chain broken	Freeze the spool, preserve cs3-ai-audit-* and the gateway spool directory, verify the chain offline, open an AU-9 incident

llm-audit-data-loss	LLM audit data loss	Record the gap window, restore delivery, reconcile from gateway logs, report per the audit policy
