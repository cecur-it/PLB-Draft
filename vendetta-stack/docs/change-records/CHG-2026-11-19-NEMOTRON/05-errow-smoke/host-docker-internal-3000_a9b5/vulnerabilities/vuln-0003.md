# File Disclosure via Path Traversal

**ID:** vuln-0003
**Severity:** HIGH
**Found:** 2026-11-19 10:37:49 UTC
**Target:** http://host.docker.internal:3000
**CWE:** CWE-22
**CVSS:** 7.5
**Confidence:** High
**Fix Effort:** Low

## Description

Path traversal in the FTP directory listing endpoint enables unauthorized retrieval of arbitrary files.

## Evidence

HTTP/1.1 200 OK response for `/ftp/package.json.bak%2500.md` containing the full backup JSON manifest; directory listing at `/ftp/` reveals backup files.

## Impact

Unauthenticated attacker can read sensitive files such as backup manifests, source maps, and configuration files, leading to information disclosure.

## Counterevidence

If the server were to sanitise the `%00` character or reject paths containing it, the bypass would fail; additionally, if the endpoint were properly restricted to specific file types, the disclosure would be prevented.

## What Would Change This Severity

If subsequent tests show that the traversal payload is blocked or returns a 404/403, the severity would decrease; if the endpoint continues to serve arbitrary files, the severity remains high.

## Technical Analysis

The FTP endpoint appears to treat directory paths as file system locations without proper sanitisation. Supplying a crafted path such as `ftp/package.json.bak%2500.md` (URL‑encoded null byte followed by `.md`) bypasses intended directory restriction and returns the contents of the target file with a 200 OK response.

## Proof of Concept

1. GET `/ftp/` – lists directory contents.
2. GET `/ftp/package.json.bak%2500.md` – returns the backup package.json file.

```carbon
curl -sD - "http://host.docker.internal:3000/ftp/"
curl -sD - "http://host.docker.internal:3000/ftp/package.json.bak%2500.md"
```

## Remediation

Normalize and validate all path inputs; reject null bytes and directory traversal sequences; serve files from a dedicated, isolated directory with no write/execute permissions.

## Assumptions

The FTP endpoint is intended for internal debugging and is unintentionally exposed; it does not require authentication.
